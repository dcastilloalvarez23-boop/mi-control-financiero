# Mi Control Financiero
Aplicación web personal para ordenar ingresos, gastos fijos, tarjetas de crédito, cuotas, viajes y proyección mensual.

## Datos
La V1 guarda los datos localmente en el navegador mediante localStorage. Incluye exportación/importación de respaldo JSON.

## Uso
Abrir index.html o publicar el repositorio como sitio estático.
